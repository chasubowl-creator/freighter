_the problem

Copying the DAW folder isn't a move.

Samples live everywhere

Drum kits on the Desktop, one-shots in Downloads, a pack on an old drive. Your projects point to all of them. A folder copy misses them.

Projects open silent

A project saved on Windows looks for C:\Users\…. On the new machine, half the sounds are gone and you're hunting files one by one.

Plugins don't copy

Licenses are tied to machines and accounts, and Windows plugins won't run on a Mac. You need a list of what to reinstall, not a folder of files.

_how it works

_faq

Questions

Does Freighter copy my plugins?

No. Plugin files don't survive a copy: licenses are tied to machines and accounts, and Windows plugins don't run on a Mac. Freighter lists every plugin by maker so you can reinstall the right version, and confirms each one once it's installed.

Are my files uploaded anywhere?

No. Everything runs on your two computers, and files travel on your own drive. Nothing is sent to our servers.

What if a project still has missing samples?

You get a list of each missing file and the project that uses it, usually samples on a drive you didn't include. Add that folder and run the move again; files already moved are skipped.

Do I need to be technical?

The beta runs from a short set of commands with step-by-step instructions. The released version is a normal app with buttons.

What about Logic, Bitwig or Reaper?

_Manifest, the plugin scan and reinstall checklist, works with any DAW today. Project repair starts with FL Studio and Ableton; tell us on the form which DAW you'd want next.
